# NGV Intelligent Mobility Engineer Track

본 저장소 구조는 지능형 모빌리티 엔지니어 트랙 운영을 위한 GitHub Organization/Repository 템플릿입니다.

## 운영 원칙

- 교육생별 Portfolio Repository를 기본 단위로 관리합니다.
- 4개의 Mini Project와 1개의 Capstone Project를 누적 제출합니다.
- 모든 결과물은 README, source, data, result, presentation, demo_video 구조를 따릅니다.
- 강사는 Issue, Commit, Pull Request 이력을 기준으로 과정 참여도와 산출물 품질을 함께 평가합니다.
