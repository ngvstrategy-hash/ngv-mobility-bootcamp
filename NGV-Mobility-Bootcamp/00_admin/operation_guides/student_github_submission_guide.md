# 교육생 GitHub 제출 가이드

## 제출 절차
1. 본인 Portfolio Repository 접속
2. 해당 프로젝트 폴더로 이동
3. README.md 작성
4. source, data, result, presentation, demo_video 폴더에 산출물 업로드
5. Commit 메시지는 `프로젝트명: 작업내용` 형식으로 작성
6. 제출 마감 전 최종 Push 완료

## Commit 메시지 예시
- `mini1: 데이터 전처리 코드 추가`
- `mini2: AI Agent 테스트 결과 반영`
- `mini3: ADAS 센서 판단 로직 수정`
- `mini4: 경로 계획 알고리즘 개선`
